# Wake-on-LAN Hub (WOL Hub)

Microservicio y dashboard web interactivo para encendido por red (Wake-on-LAN) y control de energía de equipos del homelab (PC Gaming, Proxmox VE, VMs y contenedores).

- **URL:** https://wol.davidrus.dev
- **Puerto:** 8096
- **Despliegue:** Coolify / Docker Compose en VM 101 (`coolify-server`)
